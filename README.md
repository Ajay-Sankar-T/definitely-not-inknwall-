- `addToCart(poster)`  
  - Checks if the given poster already exists in `cart`.  
  - If so, increments `qty`; otherwise, pushes a new cart item with `qty: 1`.  
  - Calls `updateCartUI()` and animates the navbar cart button.  

- `removeFromCart(id)`  
  - Filters the `cart` array to drop the matching item.  
  - Calls `updateCartUI()`.  

- `updateCartUI()`  
  - Computes `total` as sum of `price * qty` and `count` as sum of `qty`.  
  - Toggles the `.visible` state of the cart count badge and updates its text.  
  - Renders an empty‑state message if `cart.length === 0`, otherwise maps cart items to HTML including thumbnail, name with quantity, price, and a “Remove” button.  
  - Attaches click listeners to `.cart-item-remove` buttons that call `removeFromCart`.
